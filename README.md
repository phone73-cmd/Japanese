# 여행 일본어 3분 — GitHub Pages 최종본

## 포함 기능
- 반응형 UI: PC 3단 / 태블릿 2단 / 모바일 1단
- 파스텔 블루·핑크·그린·라벤더 테마
- 라이트 / 다크 모드
- 여행 일본어 1,020문장, 30개 카테고리
- 한국어/일본어 통합 검색
- 일본어 TTS 듣기
- 저장 표현
- 여행 단어장 50개 + 예문 + 암기 체크
- 10문제 랜덤 퀴즈
- LocalStorage 학습상태 저장
- PWA manifest / Service Worker / 오프라인 캐시

## GitHub Pages
1. 이 ZIP을 풀고 모든 파일을 GitHub 저장소 루트에 업로드합니다.
2. Settings → Pages → Deploy from a branch를 선택합니다.
3. main / root를 선택하고 Save 합니다.
4. 생성된 HTTPS 주소로 접속합니다.

`index.html`을 PC에서 직접 열어도 대부분 기능이 동작하지만, PWA 설치/오프라인은 HTTPS 환경(GitHub Pages)에서 사용하세요.
